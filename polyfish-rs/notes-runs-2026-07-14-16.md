  graduate at 55% rolling winrate → anchor_frac 0.5→0.05 → ~5 anchor

  bang-bang) → catastrophic forgetting → crash. Worst: iter84 (13-3) →
  iter90 (4-12, 25%) in six iterations.
- Root cause is the DEFAULT TUNING, not code: the ramp exists
  (self_play.rs, `-W`/`-P` pass-through in run_training_loop.sh) but spans
  only 50→55% with probe floor 0.05.

**PATCH SHIPPED (2026-07-18): `mirror-relative-value-labels.patch`** (repo
root, on top of 4749eb5). What it does:
- Games 2k/2k+1 share a seed (same map + tribes), controllers on swapped
  seats (`seed = base_seed + i/2`; the existing i%2 swap supplies the seat
  flip). Anchor games are scheduled per PAIR — both halves anchor, greedy on
  opposite seats — so net-vs-greedy pairs are exact mirrors.
- Value tail per step: `label = (1−u)·pair_mean + u·own_outcome`, where
  pair_mean = mean of this controller's outcome across the pair and
  u = step position in the game (0 at start → 1 at end). Early states — where
  the two halves haven't diverged and spawn luck dominates — get the
  luck-cancelled pair mean; late states keep the true ±1. A spawn-luck win
  now trains the opening as ~0, not +1. Kills the +0.24→+0.32 P1 label skew.
- Unpaired games (partner panicked) fall back to the raw outcome. Stderr
  prints `[MirrorLabels] N/M games have a live mirror partner` per run.
- `--mirror-labels` (default TRUE) — disable with `--mirror-labels=false` for
  A/B. Outcome computation extracted to `outcome_for()` (single source of
  truth; behavior unchanged from the old inline block).
- Verified: cargo check clean (only pre-existing warnings); 6-game smoke run
  paired 6/6 with anchor pairs seat-swapping correctly.

**Read rules for the mirror run**: expect value-label saturation_pct in
value_distribution.json to DROP well below ~90% (pairs that split produce
mid-range labels) — if it stays 90%+, pairing is broken. Success = R² on the
now-less-noisy target trending up AND Elo climbing within-run (newer-vs-older
> 50% sustained). Elo bench MUST use --max-turns 45.
